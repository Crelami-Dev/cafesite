01 / Alur Sinyal Real-Time

Setiap request melewati empat pos pemeriksaan sebelum menyentuh API Anda.

Geser diagram ke kanan untuk melihat seluruh pos pemeriksaan →
STEP 01 Ack 202 Kilat

Provider langsung mendapat respons sukses agar tidak memicu retry duplikat.

STEP 02 Raw Body Utuh

Payload JSON dan header signature disimpan byte-per-byte tanpa diubah.

STEP 03 Antrean Terisolasi

Jika server Anda 502 atau timeout, event masuk disk queue Jakarta.

STEP 04 Replay Presisi

Putar ulang satu event atau ratusan transaksi gagal hanya dengan satu klik.
